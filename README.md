# 💬 DissaChat — React Native / React Backend

**DissaChat** is a modern, real-time chat application frontend built with **React Native (Expo)** for mobile (and React / React.js for web where applicable). It integrates seamlessly with a Java-based backend using Servlets or Spring Boot and MySQL to provide authentication, profile management, and real-time chat via REST APIs and WebSockets.

---

## ✨ Features

* 🟢 **Real-time chat messaging**
* 🔐 **User registration & authentication**
* 👥 **One-on-one conversations**
* 🗄️ **MySQL-backed user & message storage**
* 🔄 **Live message updates through WebSockets**
* 🎨 **Modern UI with smooth animations (React Native + Expo)**
* 📸 **Profile picture upload & editing**
* 🗂️ **Posts tab for sharing images & updates**
* ✅ **Message status indicators (seen/unseen)**

---

## 🛠️ Tech Stack

### Frontend

* ⚛️ **React Native (Expo SDK)**
* **React Navigation** — Smooth screen transitions
* **Animated Components** — Enhanced UI/UX experience
* **Fetch API** — Backend communication

### Backend

* ☕ **Java (Servlets)** — REST APIs & WebSocket handling
* 🐬 **MySQL** — Persistent data storage
* 🔄 **WebSockets** — Real-time bidirectional messaging
* 🏗️ **Hibernate ORM** — Database interaction layer
* 🌐 **GlassFish Server** — Reliable backend hosting

---

## 🔎 Overview

DissaChat offers a full-featured chat experience combining frontend performance and backend scalability:

### 🔐 Authentication

* Sign Up & Sign In with validation.
* Password masking & visibility toggle.
* Animated transitions for login/signup screens.

### 💬 Chat

* Real-time one-on-one chat with live updates.
* Display of online status, timestamps, and message status.
* Seen/unseen indicators for messages.

### 👤 Profile Management

* Update name, mobile number, and profile image.
* Optional profile image upload step.

### 🖼️ Posts & Sharing

* Share images/posts through a dedicated “Posts” tab.

### 📱 Responsive UI

* Works across different mobile screen sizes.
* Built for fluid navigation and performance with Expo.
